# Analysis Tools Overview

The Analysis Tools window (🧰) is a dedicated workspace for performing on-demand analysis, diagnostics, and engineering calculations without affecting the main dashboard view.

It is accessible via the status bar button or the `Ctrl+Shift+T` keyboard shortcut.

## Available Tools

The Tools window is organized into several tabs, each serving a specific purpose:

1.  **📊 FFT Spectrum Analyzer**: Real-time frequency analysis of sensor data or audio input.
2.  **🔧 Sensor Calibration**: A wizard-based interface for calibrating sensors using linear or polynomial fits.
3.  **📈 Statistics**: Real-time statistical analysis including distributions, histograms, and trends.
4.  **🔌 Diagnostics**: Hardware health monitoring, serial port discovery, and raw serial communication.
5.  **📐 Calculator**: Engineering unit converters, RTD/NTC resistance calculators, and Ohm's Law tools.
6.  **🔁 Optical RPM Sensor**: Camera-based measurement tool for RPM and brightness events.

## AI Assistant Role

While the AI Assistant has access to some underlying tools (like calibration), it does not directly "see" or interact with the Tools popup UI elements. These documents are provided so the AI can explain the features and guide the user on how to use these interactive tools.

If a user asks how to analyze the frequency of a signal or how to calibrate a sensor manually, refer them to these tools.
